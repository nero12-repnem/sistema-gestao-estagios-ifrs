# Sistema de Gestão de Estágios — IFRS Alvorada

Sistema web para automatizar processos relacionados à geração e ao gerenciamento de Termos de Compromisso de Estágio.

## Status
**Funcional / em evolução.**

## Objetivo
Reduzir trabalho manual no fluxo de criação, registro e acompanhamento de documentos de estágio.

## Funcionalidades
- Formulário web para coleta e validação de dados
- Geração automática de documentos
- Integração com Google Docs, Drive e Sheets
- Registro de termos em planilha
- Notificações por e-mail
- Máscaras e validações para dados como CPF, CNPJ, telefone e CEP
- Upload de documentos
- Rotinas de migração de registros existentes

Dados pessoais, IDs internos, credenciais, tokens, documentos de estudantes e informações institucionais sensíveis não devem ser versionados neste repositório.

Projeto desenvolvido para resolver uma necessidade real de automação de processos relacionados a estágios.
